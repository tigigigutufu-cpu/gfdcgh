About this DNS Lookup Tool

This free DNS lookup tool queries Google's public DNS-over-HTTPS resolver directly from your browser to fetch the current DNS records for any domain. Check A and AAAA records to see hosting IPs, MX records for email routing, TXT records for domain verification (like SPF, DKIM, or Google Search Console), and more -- all in real time, with no signup and no rate limits.

Frequently Asked Questions

What is a DNS lookup tool used for?

It shows you the DNS records a domain currently publishes -- useful for verifying website hosting, email (MX) setup, domain verification (TXT) records, and troubleshooting DNS changes.

Which DNS record types can I check?

You can look up A, AAAA, MX, TXT, CNAME, NS, and SOA records by selecting the record type before searching.

Is this DNS lookup tool free?

Yes, it's completely free with unlimited lookups and no signup required.

About this tool

Look up A, AAAA, MX, TXT, CNAME, NS and other DNS records for any domain instantly — useful for verifying website setup, email configuration, and troubleshooting DNS propagation.

How to use this tool

  1. Enter the domain name you want to look up (e.g. example.com).
  2. Select the record type you need, or check all common types at once.
  3. Click Lookup to instantly see the live DNS records for that domain.

Additional FAQs

Why would I need a DNS lookup tool?

It's commonly used to verify domain setup, debug email delivery issues (MX/TXT records), or confirm DNS changes have propagated.
