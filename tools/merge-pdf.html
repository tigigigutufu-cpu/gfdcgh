About this tool

Combine two or more PDF files into a single document, in the order you select them — useful for merging scanned pages, combining reports, or assembling a single file to submit or share. Everything is processed locally in your browser; files are never uploaded to a server.

How to use this tool

  1. Click the upload box and select two or more PDF files (they'll merge in the order selected).
  2. Review the file list to confirm the order is correct.
  3. Click Merge PDFs, then download your combined file.

Frequently asked questions

Are my PDF files uploaded to a server?

No, all merging happens locally in your browser using client-side processing. Your files never leave your device.

Is there a limit on file size or number of PDFs?

You can merge multiple PDFs, though very large files may take longer to process depending on your device.

Will the merged PDF have a watermark?

No, the output is a clean, watermark-free PDF.

Can I reorder the files before merging?

Files merge in the order you select them in the upload dialog; select them in your desired final order.
