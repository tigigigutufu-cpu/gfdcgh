Frequently asked questions

How long should a YouTube description be?

The first 1-2 lines matter most since they show before 'Show more'. Full descriptions can run up to 5000 characters.

How many hashtags can I add?

YouTube shows up to 3 hashtags above your title; you can include more inside the description.
