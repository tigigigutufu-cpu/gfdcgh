About this tool

Estimate the future value of a monthly Systematic Investment Plan (SIP) using the standard compound-growth SIP formula. Actual mutual fund returns are market-linked and not guaranteed.

Frequently asked questions

Is the SIP return guaranteed?

No. This is an estimate based on your assumed rate of return; actual mutual fund returns fluctuate with the market.

What return rate should I assume?

Many long-term equity SIPs historically averaged 10-14% p.a. in India, but past performance doesn't guarantee future returns.
