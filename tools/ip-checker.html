About this IP Address Checker

This free tool detects your public-facing IP address the moment you load the page, along with its approximate country, region, city, and internet service provider. You can also look up any other public IP address, and every result is checked against the official Tor Project exit node list so you can tell if traffic from that IP is likely coming through the Tor anonymity network.

Frequently Asked Questions

How do I find my IP address?

Just open this page -- your public IP address, along with your approximate city, country and ISP, is detected and shown automatically.

Can I look up someone else's IP address?

Yes, enter any public IP address in the search box to see its approximate location and network provider.

What does the Tor exit node check mean?

We compare the IP address against the official Tor Project exit node list. If it matches, the traffic from that IP is likely exiting the Tor anonymity network.
